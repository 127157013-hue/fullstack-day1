# Full-Stack Blog Application

A full-stack blog application built during my Full-Stack Development Internship at Codomax Digital Solutions.

## 🚀 Live Demo
[View Live Site](https://github.com/127157013-hue/fullstack-day1)

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS, JavaScript (DOM, Fetch API)
- **Backend:** Node.js, Express.js
- **Version Control:** Git & GitHub

## ✨ Features
- Home page and Blog page with responsive navigation
- Add new blog posts with real-time form validation
- View all blog posts dynamically (fetched from backend API)
- Edit existing blog posts
- Delete blog posts with confirmation
- Smooth animations, hover effects, and scrolling
- Fully responsive design (mobile, tablet, desktop)
